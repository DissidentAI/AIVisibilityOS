# Licence proposée / Proposed license

Décision initiale réversible avant publication : **AGPL-3.0-only** pour le code original. Le fichier LICENSE contient le texte complet, récupéré depuis le [référentiel SPDX](https://github.com/spdx/license-list-data/blob/main/text/AGPL-3.0-only.txt). Le dépôt n’est pas automatiquement rendu public par l’ajout d’une licence.

Sources officielles : [texte AGPLv3 et approbation OSI](https://opensource.org/license/agpl-3.0), [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0).

L’AGPL soutient une proposition commerciale fondée sur l’hébergement, le support et les services. Elle **n’interdit pas** de concurrencer ce projet, de vendre son hébergement ou de l’utiliser dans une entreprise. Ne pas ajouter de clauses « usage non commercial », « interdiction des SaaS concurrents » ou autres restrictions en présentant le résultat comme AGPL/open source.

Avant publication, vérifier droits sur les contributions et compatibilité des dépendances. Un module propriétaire dérivé/lié n’est pas automatiquement exempt du copyleft ; faire examiner l’architecture juridique avant de promettre un modèle open core. Une double licence exige les droits nécessaires de tous les contributeurs concernés. Les obligations exactes dépendent de la distribution et des modifications ; cette note décrit le choix produit, elle ne remplace pas la licence.

Apache-2.0 serait une alternative cohérente si l’adoption et l’intégration propriétaire priment sur la réciprocité du code servi. Aucune restriction fictive ne doit lui être attribuée.
