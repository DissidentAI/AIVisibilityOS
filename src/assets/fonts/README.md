# PDF font

Noto Sans CJK SC Regular, from the official [Noto CJK repository](https://github.com/notofonts/noto-cjk/blob/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf), pinned at commit `f8d157532fbfaeda587e826d4cd5b21a49186f7c` on 2026-11-01.

Unmodified OTF. SIL Open Font License 1.1 included as `OFL.txt`. Embedded subsets allow offline, selectable Simplified Chinese text in PDFs without a remote font request. Regular/bold Latin faces come from the pinned `@fontsource/noto-sans` package. Render implementation follows the [PDFKit text and font documentation](https://pdfkit.org/docs/text.html).
